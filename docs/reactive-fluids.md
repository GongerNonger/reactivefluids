# Reactive Fluids System

## Concept

The core mechanic that gives the mod its name. Three color families of fluids react when combined:

| Family | Resin Color | Hardener Color | Epoxy Result |
|--------|-------------|----------------|--------------|
| **Amber** | Warm orange/gold | Bright yellow-gold | Golden transparent block |
| **Cobalt** | Deep blue | Cyan-blue | Blue transparent block |
| **Jade** | Deep green | Lime green | Green transparent block |

## Fluid Behavior

### Resin (Slow)
- Tick delay: 25 (very slow flow)
- Slope find distance: 2 (doesn't spread far laterally)
- Level decrease per block: 2 (loses height quickly)
- Viscosity: 3000, Density: 1500
- Implemented via `SlowSource`/`SlowFlowing` inner classes in `ModFluids`
- Texture alpha: 80 (clearly translucent)
- Animation: `interpolate: false` for thick, sharp drip appearance

### Hardener (Throwable Item)
Hardener is **not a fluid** — it's a throwable item like a splash potion. Three variants: Amber, Cobalt, Jade. Stack size: 16.

On right-click, `HardenerItem` spawns a `HardenerEntity` projectile. On impact, the entity:
1. Checks 7 candidate positions (impact point + 6 cardinal neighbors)
2. For each position containing matching-color resin, performs BFS flood-fill
3. Converts up to 1024 connected resin blocks to epoxy
4. Regular resin becomes transparent epoxy; glowing resin becomes glowing epoxy
5. Each converted block emits CLOUD + POOF particles server-side

### Glowing Resin
Same flow properties as regular resin but with alpha 100 and light level 8. Crafted from resin bucket + glow ink sac. Reacts with hardener to produce glowing epoxy (light level 12).

## Epoxy Blocks

| Variant | Hardness/Blast | Light | Render | Sound |
|---------|---------------|-------|--------|-------|
| Transparent | 2.5 / 6.0 | 0 | Translucent, no occlusion | Glass |
| Glowing | 2.5 / 6.0 | 12 | Translucent, no occlusion | Glass |
| Solid (Opaque) | 3.0 / 8.0 | 0 | Standard solid | Stone |

Opaque epoxy is crafted from transparent epoxy + ink sac.

## Additional Fluids

### Elephant's Toothpaste
Hydrogen peroxide fluid + catalyst triggers expanding foam block eruption. Growth is capped at 20 blocks per reaction to prevent server lag from runaway expansion.

### Acid
Dissolves stone-type blocks downward on contact, exposing ores underneath. Useful as a mining tool.

### Bioluminescent Plankton
Reactive glow fluid. When plankton blocks are set on fire, they emit bright blue particle eruptions. Decorative/atmospheric.

### Crystal Solution
Grows crystal block structures when placed. Experimental feature on the testing branch.

## Technical Notes

### Translucent Rendering
NeoForge's fluid renderer ignores tint color alpha — transparency only comes from the texture's own alpha channel. Additionally, the default fluid render pass can override `ClientEvents` render layer assignments. `TranslucentLiquidBlock` (extends `LiquidBlock`) solves both issues by setting the render layer at the block level.

### Texture Generation
All fluid textures are procedurally generated by `generate_textures.py`:
- **Still textures**: 16x16 frames, 32 frames stacked vertically (16x512 total). 5 pure-X + 5 pure-Y sinusoidal wave layers, dual specular blobs, horizontal sheen gradient.
- **Flow textures**: 16x512 with pure vertical ribbon system. Per-column static brightness profile, 3 drip waves per column, downward scroll only.
- **Bucket sprites**: 16x16 with steel handle/walls and per-fluid fill color with highlight/shadow zones.

Run `python generate_textures.py` after any color or art change.
